# Phase 06.13 — Foundations design system — CONTEXT

## Goal

Poser les fondations conceptuelles d'un design system TAP formalisé :
doctrine accessibilité datée, design tokens W3C-standard, catalogue de
patterns existants documenté, benchmark FOSS sourcé. **Aucune refonte
d'écran dans cette phase.** L'exécution viendra dans des phases
ultérieures.

## Doctrine d'accessibilité TAP (DEC-088)

- Visée : **WCAG 2.1 AA + RGAA 4.1.2** dès Phase 06.13.
- Transition WCAG 2.2 envisagée Phase 09 HDS ou équivalent.
- Rationale : RGAA 4.1.2 reste la transposition française de référence
  pour 2026. Pas de sur-engagement prématuré tant qu'aucun audit formel
  n'est exigé par un client. Le RGPD impose `démontrer` la conformité ;
  l'accessibilité impose `viser` un niveau et le `documenter`.
- Tous les composants TAP doivent au minimum : contraste 4.5:1, focus
  visible, navigation clavier, doublement couleur+texte, ARIA landmarks
  pour structure de page, skip links pour clavier-only.
