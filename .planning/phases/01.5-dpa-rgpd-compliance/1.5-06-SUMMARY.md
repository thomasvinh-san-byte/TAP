## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 — Blocking] Renommage route.ts → route.tsx**

- **Found during:** Task 6.3, première typecheck pass
- **Issue:** Le plan listait `apps/web/src/app/api/admin/legal/registre/pdf/route.ts` mais le fichier contient du JSX (`<RegistrePdf .../>` dans renderToStream). TypeScript parser réclame `.tsx` ou `React.createElement`.
- **Fix:** Rename `.ts` → `.tsx`. Pattern Next.js 14 standard pour les routes contenant du JSX. Pas de régression — Next.js détecte les deux extensions pour les fichiers `route.{ts,tsx}`.
- **Files modified:** `route.ts` → `route.tsx`
- **Commit:** 9d90c11

**2. [Rule 3 — Blocking] breach-drawer.client.tsx 170 → 139 lignes (split breach-form-fields)**

- **Found during:** Task 6.2 acceptance check (≤150 lignes)
- **Issue:** Premier draft 170 lignes avec 2 select fields inlinés + 2 checkboxes répétées.
- **Fix:** Extraction `breach-form-fields.client.tsx` (53l) avec composants réutilisables `SelectField`, `CheckboxField`, et constantes `SEVERITY_OPTS`, `NATURE_OPTS`. breach-drawer descend à 139 lignes.
- **Files modified:** `breach-drawer.client.tsx` (refactor) + `breach-form-fields.client.tsx` (créé)
- **Commit:** f7cd385

**3. [Rule 3 — Blocking] ExportPdfButton client component créé**

- **Found during:** Task 6.3 alignment avec test E2E
- **Issue:** Le test `tests/admin/registre-pdf.spec.ts` fait `page.getByRole('button', { name: /exporter pdf/i }).click()`. Si on rend `<Button asChild><Link href="/api/...">` le DOM résultant est un `<a role="link">`, pas un `<button>`. Test E2E ne trouverait pas l'élément.
- **Fix:** Création `ExportPdfButton` client component (22l) avec `<Button type="button" onClick={() => window.open('/api/...', '_blank')}>`. Élément DOM `<button>` natif → role="button" implicite, satisfait `getByRole('button', name: /exporter pdf/i)`.
- **Files modified:** Création + page.tsx import
- **Commit:** 9d90c11

**4. [Rule 2 — Missing critical] Type Entry exporté depuis registre-pdf**

- **Found during:** Task 6.3 — réduction route.tsx pour respecter le « max_lines: 60 »
- **Issue:** Le type Entry inline dans route.tsx (10 lignes type literal) gonflait le fichier. La déclaration redondante avec le composant PDF aurait causé deux drift potentiels (champs DB renommés une seule fois).
- **Fix:** Export du type `Entry` depuis `registre-pdf.tsx`. route.tsx importe `{ RegistrePdf, type Entry }`. Single source of truth.
- **Files modified:** `_components/registre-pdf.tsx` (ajout export type) + `route.tsx`
- **Commit:** 9d90c11
