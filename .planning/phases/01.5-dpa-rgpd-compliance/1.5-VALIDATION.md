### DPA-04 — Portail patient (art. 15-20 RGPD)
- **Test type:** Vitest (helpers purs) + Playwright E2E (flow complet)
- **Files:**
  - `packages/shared/src/utils/__tests__/legal-token.test.ts` (sign/verify JWT HS256, claims minimaux `{sub, org, type}`, expiry 30j, rejet token expiré, rejet algo non-HS256, rejet signature invalide, rejet token malformé)
  - `packages/shared/src/utils/__tests__/patient-data-export.test.ts` (format JSON `format_version: '1.0'`, présence `patient`, `operational_notes`, `constraintes`, `audit_log`, vérif que NIR clair n'apparaît jamais sans appel explicite Edge Function `nir`)
  - `packages/shared/src/utils/__tests__/patient-anonymize.test.ts` (helper appelle RPC `rgpd_anonymize_patient`, propage erreur traduite en français, jamais de DELETE direct)
  - `supabase/tests/patient_data_request_rls.sql` (RLS forcée + token jamais retourné en SELECT pour rôles non-dirigeant + rate-limit table `legal_request_attempts` insertable service_role only)
  - `supabase/tests/rgpd_anonymize_patient.sql` (RPC SECURITY DEFINER : exécute UPDATE patients (nom/prenom/telephone NULL, archive=true), conserve `rides`/`ride_billings`, hash NIR via pgcrypto sha256+salt, insère audit_logs `patient.anonymized`, advisory lock, rejet si appelé sans request_id valide)
  - `apps/web/tests/portail/access-flow.spec.ts` (E2E : ouvre URL `/legal/request/[token]` → form identité (NIR + nom + DDN) → access page → assertion JSON contient `format_version: '1.0'` ET clé `nir` ; teste aussi rate-limit 5/h → 6e tentative bloquée ; teste flow erasure → assert `patients.nom IS NULL` + `rides.count > 0` après anonymisation)
- **Verifies:** JWT HS256 sign/verify avec secret `APP_LEGAL_TOKEN_SECRET` ; token contient uniquement `request_id`, `org`, `type` (pas de PII) ; expiry alignée 30j sur `request_token_expires_at` DB ; identity check via vérification NIR/nom/DDN côté Server Action service_role ; export JSON portable conforme art. 20 ; effacement art. 17 = UPDATE only (jamais DELETE) ; intégrité référentielle préservée pour conservation CGSS 5 ans ; audit log `patient.anonymized` toujours inséré.

```bash

# Équivalent : supabase test db --file supabase/tests/<name>.sql
```
