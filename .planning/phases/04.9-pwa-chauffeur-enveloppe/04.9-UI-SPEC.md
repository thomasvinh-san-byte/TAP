## Sources industrie 2026 consultées (8)

1. **web.dev/learn/pwa/enhancements** (Google official) — splash iOS = images statiques par DPR via `apple-touch-startup-image`. Pas de splash auto iOS. Android génère via manifest.
2. **coywolf 2026-01** — PWA icons 3 modes : iOS/iPadOS Safari (`apple-touch-icon` HTML, carré sans padding, Apple ajoute squircle), Safari macOS (manifest forme macOS), Chrome Android (manifest `maskable` avec safe zone). Recommandation : 3 icônes distinctes pour rendu propre toutes plateformes.
3. **firt.dev iOS PWA compatibility 2026** — `apple-touch-icon` HTML **écrase** manifest icons sur iOS Safari (override systémique). Donc déclarer en HTML, pas seulement manifest.
4. **magicbell 2026-03 PWA iOS limitations** — PWA standalone iOS 16.4+, iOS 17.4 EU = mode browser tab (DMA, hors EU OK). Stockage IndexedDB serré (purge ~2sem si pas home screen, cf DEC-022). **No `beforeinstallprompt` iOS** (tutoriel manuel via share sheet). No fullscreen API. No background sync (fallback online listener).
5. **css-tricks notch + safe-area 2017+** + **dev.to PWAs handsome iOS 2021** + **danielpietzsch 2025** — `<meta viewport content="viewport-fit=cover">` pour cover notch. `apple-mobile-web-app-capable=yes` (deprecated iOS 26+ mais fallback). `apple-mobile-web-app-status-bar-style=black-translucent` pour statusbar transparente. CSS `env(safe-area-inset-{top,right,bottom,left})` pour fixed elements. Pattern blurry statusbar : `body::before` + `backdrop-filter: blur()` + `mask linear-gradient` + height `env(safe-area-inset-top)`.
6. **web.dev manifest 2026** + **firt.dev** — Manifest standard : `name`, `short_name` (max ~12 chars), `description`, `start_url`, `scope`, `display: 'standalone'`, `orientation: 'portrait'`, `theme_color` (toolbar/statusbar Android), `background_color` (splash Android), `icons[]`.
7. **logrocket touch targets 2024** + **mobileviewer 2026-02** — Material Design 3 : 48dp min, 56dp recommandé primary, 56-96dp FAB. Apple HIG : 44pt min. Driver app contexte (gants, pluie, conduite) : **56px minimum** (DEC-014 LOCKED), idéal 64-72px primary CTA. Spacing 8-12px entre targets. Test glove-wearing obligatoire.
8. **web.dev offline UX 2016** + **netguru PWA UX 2025-11** + **Material Design offline states** — Indication offline OBLIGATOIRE (Flipkart noir/blanc, Starbucks message). Action-based language pas tech. Queue actions for later. Icons : `cloud_off` offline, `offline_pin` cache local OK. Position : bottom snackbar non-bloquant OU top banner persistant selon criticité.

## Périmètre — 3 composants nouveaux

### 1. `ConnectionStatus` (badge intégré au header sticky, 4 états)

**Position** : intégré dans le header existant `driver/layout.tsx` ligne 31-49, à côté du `UserMenu`. **PAS de banner full-width** qui pousserait le contenu (anti-pattern vu Material Design : indication offline doit être visible sans amputer la surface utile).

**Pour iOS standalone** : le header inclut déjà `padding-top: env(safe-area-inset-top)` (extension DriverShell § 2).

**4 états** :

| État | Trigger | Affichage |
|------|---------|-----------|
| `online_idle` | `navigator.onLine && pendingCount === 0` | RIEN visible (header normal, pas de pollution UI) |
| `synching` | `navigator.onLine && pendingCount > 0` | Badge pulse + Lucide `RefreshCw` (rotation animée) + couleur `primary` subtile + texte « Sync… N » |
| `offline_with_queue` | `!navigator.onLine && pendingCount > 0` | Badge clignotant lent + Lucide `CloudOff` + compteur `pendingCount` + couleur `warning` (orange/amber) + texte « Hors-ligne · N » |
| `offline_idle` | `!navigator.onLine && pendingCount === 0` | Badge stable + Lucide `CloudOff` + couleur `muted` (gris) + texte « Hors-ligne » |

**Anti-patterns interdits** :
- ❌ Banner full-width qui pousse le contenu
- ❌ Modal bloquante
- ❌ Texte « offline » seul sans icône (illettrisme défense, Material Design § offline states)
- ❌ Couleur `destructive` (rouge) sauf dead letter queue (cf plan Wave 4 toast Sonner destructive)
- ❌ Re-render full header à chaque tick (isoler dans composant `ConnectionStatusBadge` indépendant)

**Implémentation hint** :
- `useLiveQuery` Dexie sur `mutations_queue.where('status').equals('pending').count()` (Wave 4 du plan)
- `useEffect` listeners `online`/`offline` events sur `window`
- Composant client isolé `apps/web/src/app/(driver)/conduite/_components/connection-status-badge.client.tsx`
- Pas de polling, réactif sur events

### 2. `DriverShell` extensions PWA-aware

Le shell existe déjà (`driver/layout.tsx`). Extensions à apporter Wave 5 du plan :

**Safe-area iOS notch / Dynamic Island** :
- Layout root `apps/web/src/app/layout.tsx` : `<meta viewport content="width=device-width, initial-scale=1, viewport-fit=cover">`
- `<header>` driver/layout : `padding-top: env(safe-area-inset-top)` pour iOS notch
- `<main>` driver : `padding-bottom: env(safe-area-inset-bottom)` pour home indicator iPhone X+
- Modals fixed (end-ride-modal Phase 04.7) : padding 4 côtés safe-area (à valider Wave 5 si déjà conforme)

**Standalone detection** :
- Hook `useIsStandalone()` (client) :
  ```ts
  const isAndroid = window.matchMedia('(display-mode: standalone)').matches;
  const isIOS = (window.navigator as any).standalone === true;
  return isAndroid || isIOS;
  ```
- Usage : afficher tutoriel « Add to Home Screen » si non-standalone iOS Safari (no `beforeinstallprompt` iOS — magicbell § 4)

**Splash transition** :
- Au mount PWA, splash OS-level (iOS apple-touch-startup-image, Android manifest auto)
- Hydration RSC `/conduite/page.tsx` se fait derrière
- DEC-020 fade-in `template.tsx` LOCKED : transition douce entre routes après hydration
- PAS de loader spinner intrusif après splash OS (l'OS gère)

**Theme color cohérent** :
- `<meta name="theme-color">` = couleur header background
- Android : statusbar suit `theme_color` automatiquement
- iOS : `apple-mobile-web-app-status-bar-style="black-translucent"` + (option premium) `body::before` blur statusbar (cf source 5)

### 3. `WarningBannerInactivity` (DEC-022 > 7j inactivité)

**Trigger logic** :
- Au mount `/conduite`, lire `lastUsedAt` depuis IndexedDB (table `app_meta` à créer Wave 3)
- Si `Date.now() - lastUsedAt > 7 * 24 * 3600 * 1000` ms : afficher banner
- Toujours mettre à jour `lastUsedAt = Date.now()` au mount (idempotent)
- Si IndexedDB vide (premier mount ou purgé iOS) : PAS de warning (fresh start, rien à signaler)

**UI** :
- Banner non-bloquant top du `<main>`, fond `bg-amber-50` (warning subtil light), bordure `border-amber-200`, texte `text-amber-900`
- Lucide `AlertTriangle` icône 20×20
- Texte action-based (Material Design § offline states) : « Bienvenue. Si tu as un problème de chargement, ferme et relance l'app. »
- Bouton « Compris » dismiss (state local + flag IndexedDB `warningDismissed: true`)
- PAS de modal bloquante (chauffeur veut voir ses courses)

**Edge case** :
- IndexedDB purgé iOS après 2 semaines : `lastUsedAt` introuvable → fresh start, pas de warning (correct UX, l'utilisateur n'a rien à corriger)
- Dismiss persistant via flag IndexedDB : ne pas réafficher tant que `lastUsedAt > 7j` reste vrai dans la même session

## Anti-patterns interdits (verrouillés cette phase)

1. ❌ **Banner full-width ConnectionStatus** qui pousse le contenu (intégrer au header existant)
2. ❌ **`apple-mobile-web-app-capable` seul sans manifest** (web.dev anti-pattern source 5 — fallback UX inconsistent)
3. ❌ **Touch targets < 56px** (DEC-014 LOCKED ergonomie chauffeur gants/pluie/conduite)
4. ❌ **Modal sans safe-area padding** (iPhone moderne → contenu sous notch/Dynamic Island invisible)
5. ❌ **Splash iOS skip** sous prétexte économie (Option B/C verrouillées PR #109, Option A LOCKED)
6. ❌ **Texte « offline » seul sans icône** (illettrisme défense, Material Design § offline states obligatoire)
7. ❌ **Couleur destructive (rouge) ConnectionStatus** (réservée dead letter queue toast Sonner)
8. ❌ **Modal bloquante warning inactivité** (chauffeur veut voir ses courses, dismiss non-bloquant)
9. ❌ **Polling navigator.onLine** (utiliser events online/offline réactifs)
10. ❌ **Re-render full header à chaque tick Dexie** (isoler `ConnectionStatusBadge` client component)
