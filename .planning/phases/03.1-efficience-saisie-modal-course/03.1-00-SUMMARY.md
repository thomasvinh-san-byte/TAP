## Pourquoi Wave 0 était indispensable

Sans cette décompression :
- Plan 01 (smart defaults) aurait ajouté ~25 L dans le modal → **409 L** (breach).
- Plan 03 (détection doublons + DuplicateBanner instancié) aurait ajouté
  ~50 L dans le modal → **459 L** (breach majeur).
- Plan 01 aurait également ajouté `getPatientRideDefaultsAction` (~30 L)
  dans `patients/actions.ts` (293 L) → **323 L** (breach).

Avec Wave 0 (modal à 274 L, barrel patients/actions en place) :
- Plan 01 peut ajouter +25 L au modal (→ 299 L max) et ajouter
  `actions/get-ride-defaults.ts` (~30 L self-contained).
- Plan 03 peut ajouter +25 L au modal (→ 324 L max) → **encore breach
  potentiel**. Note pour Plan 03 : prévoir une extraction supplémentaire
  (par exemple `use-ride-duplicates.client.ts`) si le delta dépasse 25 L.
