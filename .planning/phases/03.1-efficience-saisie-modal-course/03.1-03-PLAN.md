**Signature Server Action attendue** :
```typescript
'use server'
export async function checkDuplicateRideAction(input: {
  patientId: string;
  scheduledAt: string;       // ISO
  excludeRideId?: string;    // mode édition : exclure la course elle-même
}): Promise<{
  data?: Array<{ id: string; scheduled_at: string; status: string }>;
  error?: string;
}>
```

**Critères de détection (D-B3-2)** :
- `patient_id = input.patientId`
- `scheduled_at` ∈ `[input.scheduledAt - 30min, input.scheduledAt + 30min]`
- `archive = false`
- `status ∈ {'validee', 'assignee', 'en_cours', 'terminee'}`
- `id != input.excludeRideId` si fourni

**Pattern Server Action** (template `courses/actions/edit.ts`) :
1. `'use server'` en tête.
2. zod safeParse de l'input (patientId UUID, scheduledAt ISO string, excludeRideId UUID optionnel).
3. `getAuthContext()` + assertion rôle REGULATEUR_OR_DIRIGEANT.
4. Supabase select RLS-filtré.
5. Retour `{ data }` ou `{ error: 'Vérification doublon indisponible.' }` (reformulation FR).

**State modal à ajouter** :
```typescript
const [duplicates, setDuplicates] = useState<Array<{
  id: string; scheduled_at: string; status: string;
}>>([]);
const [duplicateConfirmed, setDuplicateConfirmed] = useState(false);
```

**Flow `handleSubmit` modifié** :
```
1. Si !duplicateConfirmed :
   a. Appeler checkDuplicateRideAction({ patientId, scheduledAt, excludeRideId: props.rideId })
   b. Si result.data.length > 0 : setDuplicates(result.data), return early (pas de création)
2. Sinon (ou si pas de doublon) : flow normal createRideAction / updateRideAction
3. Sur succès : setDuplicateConfirmed(false), setDuplicates([]), props.onClose()
```

**Instanciation `<DuplicateBanner>` dans le JSX du modal** — position : juste
avant `<DialogFooter>` (UI-SPEC) :

```tsx
<DuplicateBanner
  duplicates={duplicates}
  isPending={isPending}
  onCancel={() => setDuplicates([])}
  onConfirm={() => {
    setDuplicateConfirmed(true);
    handleSubmit();
  }}
/>
```

(`isPending` = état `useTransition` déjà présent dans le modal pour
l'auto-save Wave 3 ou pour le submit principal. Vérifier le nom exact.)

**Le composant `DuplicateBanner` retourne `null` si `duplicates.length === 0`** —

Simplement instancier le composant et laisser sa garde interne décider.
