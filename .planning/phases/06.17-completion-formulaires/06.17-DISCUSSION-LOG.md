# Phase 06.17 — DISCUSSION LOG

## Arbitrage

Aucun débat d'architecture — application directe des **normes UX/a11y
consensuelles** :

- **NN/G — Form Design Guidelines** : helper text persistant pour
  format/contrainte, placeholder = exemple court qui peut disparaître
  sans perte critique.
- **Deque — University on placeholders** : le placeholder n'est pas
  un label de substitution, et son contraste est souvent insuffisant.
- **Shopify Polaris — Form patterns** : helper text sous le champ,
  lié par `aria-describedby`.
- **USWDS (US gov) — Form input** : helper text persistant ; numériques
  bornés sans spinner (`inputMode="numeric"` + `pattern="[0-9]*"`).
- **W3C ARIA Authoring Practices Guide — Editable combobox with list
  autocomplete** : pattern de référence (role, aria, clavier).

Rien à arbitrer par le dirigeant. Décisions D-01..D-08 = application
directe de ces normes au code TAP.
