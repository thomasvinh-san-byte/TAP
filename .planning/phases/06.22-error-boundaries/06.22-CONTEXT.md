# Phase 06.22 — CONTEXT

> Error boundaries par segment. Troisième et dernière amélioration pré-prod priorité haute.

## Pourquoi

Avant cette phase : 1 seul `error.tsx` segmenté (tableau-de-bord) + le `global-error.tsx` root (06.20). Si une page de cockpit, conduite, admin ou public plantait, l'utilisateur tombait sur la boundary root (UI brutale) ou un écran blanc. RETEX : résilience UI par zone. ROI : empêcher les écrans blancs en exploitation, surtout côté chauffeur terrain.

**Sentry est désormais installé (06.20)** → chaque boundary capture l'erreur automatiquement. Le gabarit avant cette phase (`tableau-de-bord/error.tsx`) ne le faisait pas — corrigé.
