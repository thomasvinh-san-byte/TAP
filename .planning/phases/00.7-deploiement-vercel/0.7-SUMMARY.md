## Goal recap

Permettre le respect du **Visible Progress Mandate** (CLAUDE.md § 13.5) sur toutes les phases ≥ 2 : URL preview Vercel cliquable + seed démo réaliste 974 + comptes démo persistants + smoke test cloud + showcase artifacts.

## Approche réelle livrée

Pivot stratégique pendant l'implémentation : **plutôt que cliquer dans Vercel UI / Supabase UI à chaque rotation**, deux workflows GitHub Actions automatisent toute la configuration. Total intervention humaine : ~6 secrets GitHub à ajouter une fois + 1 clic Run workflow.

### Architecture cible


## Walkthrough — bring-up à neuf

1. **Créer un projet Supabase** (Dashboard → + New project, Frankfurt, Free) → noter le ref + le DB password
2. **Récupérer les 6 secrets ci-dessus** depuis Vercel/Supabase dashboards
3. **Coller les 6 secrets dans GitHub** : https://github.com/thomasvinh-san-byte/tap/settings/secrets/actions/new
4. **Lancer setup-vercel.yml** : https://github.com/thomasvinh-san-byte/tap/actions/workflows/setup-vercel.yml → Run workflow
5. **Push n'importe quel commit sur main** (cd.yml a tourné automatiquement à la création du projet, mais re-trigger pour migrations + Edge Functions deploy si nécessaire)
6. **Attendre 2-3 min** que Vercel rebuild avec env vars en place
7. **Ouvrir `https://tap-web.vercel.app/login`** → comptes démo visibles → login `regulateur@demo.tap` / `demo1234!` → `/patients` liste les 10 seedés → Cmd+Shift+K ouvre modal saisie
