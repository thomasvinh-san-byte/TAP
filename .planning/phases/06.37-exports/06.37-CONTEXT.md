## Décisions fermées

### D-01 — Export CSV des courses

`apps/web/src/app/(app)/courses/actions/export-rides.ts` :
- Zod schema `{ from, to, driverId?, status?, transportMode? }`
  (refine : `from ≤ to`).
- Guard `requireAdminOrRegulateur`.
- Query directe sur `rides` (RLS) + hydratation labels
  patient/chauffeur en 2 lookups (pas de FK polymorphe).
- **Colonnes** : Date RDV, Patient, Départ, Destination, Mode
  transport, Statut, Chauffeur, Tarif (€). Le tarif est lu de
  `tarif_amount_eur` déjà calculé — pas de recalcul de pricing.
- Filename : `courses_AAAA-MM-JJ_AAAA-MM-JJ.csv`.

UI : `<ExportCsvButton>` (`courses/_components/export-csv-button.client.tsx`)
dans la toolbar de `RidesList`. Pattern download client (Blob + a.click).
**Variant `outline`** (bouton normal — exporter n'est pas un moment-clé
d'avancement, pas de terracotta lot 2).

### D-02 — Export statistique CSV

`tableau-de-bord/_lib/export-stats.ts` :
- Guard `requireDirigeant`.
- Réutilise `getDashboardData()` — **0 duplication d'agrégat**.
- Format : 1 CSV avec sections séparées par lignes vides
  (volume, incidents, chauffeurs, CA + comparatif N-1).
- Filename : `stats_AAAA-MM.csv`.

UI : `<ExportStatsButton>` dans le slot `actions` du PageHeader
tableau de bord.

### D-03 — Export PDF récap chauffeur / période

Route `app/api/admin/chauffeurs/recap/pdf/route.tsx` :
- `runtime nodejs` + `renderToStream` (pattern facturation).
- Params : `?driver=<uuid>&from=YYYY-MM-DD&to=YYYY-MM-DD`.
- Guard rôle dirigeant + audit log AVANT le rendu
  (`chauffeur.recap.exported_pdf`).
- Réutilise `PdfDocument` + `PdfSection` + `pdfStyles` (charte
  commune avec facturation CGSS).
- Sections : Résumé (nb courses + nb terminées + total €) + Détail
  (table date/patient/trajet/statut/tarif).

UI : `<RecapPdfButton>` dans `DriverRowActions` (visible dirigeant
uniquement). Dialog mini-form (from/to) → ouvre la route dans un
nouvel onglet.
