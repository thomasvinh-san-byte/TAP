# Phase 06.38 — CONTEXT

> Regroupement de la navigation principale en menus déroulants pour
> désencombrer le header dirigeant (passé de 5 à 11 entrées avec le
> temps). Sans sidebar — repoussée si besoin persiste.

## Pourquoi (recherche secteur)

Standard : top-bar = **5-7 entrées primaires max**. Au-delà, elle
s'encombre et perd sa hiérarchie. TAP dirigeant = Tableau de bord +
Cockpit + Patients + Courses + Caisse + Chauffeurs + Véhicules +
Tarifs + Facturation + Conformité + Maintenance + Légal ▾ = **11
liens directs** + 1 menu.

Régulateur (5 entrées) **n'est PAS** surchargé — son flux quotidien
doit rester en accès direct.

Décision dirigeant : regroupement (pas sidebar). Le pattern déroulant
existe déjà (`LegalNavMenu` regroupe les 6 pages RGPD via
`DropdownMenu`) → réutiliser comme modèle.

### D-02 — Régulateur : accès directs préservés

Régulateur conservé à 5 entrées plates (Cockpit, Patients, Courses,
Caisse, Chauffeurs). Pas de menu Flotte/Gestion pour lui — il ne voit
pas Véhicules/Tarifs/Facturation/Conformité/Maintenance de toute
façon. Son flux quotidien reste 1 clic.

### D-03 — Pattern déroulant généralisé

Création de **`<NavGroupMenu>`** (`components/nav-group-menu.client.tsx`)
— prend une prop `group: NavGroup` et rend un `DropdownMenu` shadcn
stylé comme un onglet de la top-bar :
- Déclencheur `text-primary font-medium` + soulignement `bg-primary`
  **3px pleine opacité** quand un item du groupe est actif (cohérent
  DEC-115 — l'item actif reste **repérable même dans un menu**).
- Items du menu marqués `aria-current="page"` et `text-primary
  font-medium` quand actifs.
- A11y : `DropdownMenu` shadcn gère la navigation clavier (Espace,
  Entrée, flèches, Échap).

**`LegalNavMenu`** réécrit pour suivre exactement le même style
(passage 2px → 3px, `text-foreground` → `text-primary` actif), tout en
conservant son entrée additionnelle « Vue d'ensemble » + séparateur
(d'où la non-réutilisation directe de `NavGroupMenu`). Items et
préfixes actifs lus depuis `LEGAL_NAV_GROUP` (`nav-config`) — source
unique.

### D-04 — `nav-config` source unique

Nouvelle structure :

```ts
export interface NavGroup {
  label: string;          // « Flotte »
  activePrefixes: string[]; // ['/admin/vehicules', '/admin/conformite', ...]
  items: NavTab[];        // liens du menu
}

export interface RoleNav {
  primary: NavTab[];
  groups: NavGroup[];
}

export function navForRole(role: string): RoleNav;
```

`tabsForRole` conservé en rétro-compat (renvoie `primary` seul).
`AppHeader` consomme `navForRole(role)` et boucle sur `groups` →
`<NavGroupMenu group={...} />`.
