### D-02 — Tester le COMPORTEMENT réel

Lecture des policies AVANT écriture de chaque test pour ne pas tester un comportement générique copié. Exemples :
- `cgu_acceptance` : isolation par `profile_id = auth.uid()` (PAS par org).
- `cookie_consent_log` / `legal_request_attempts` : `service_role` ONLY (vérification par `pg_policies` + privilèges `authenticated`/`anon` = aucun).
- `ride_events` : INSERT chauffeur autorisé SUR SES rides via subquery `drivers.profile_id = auth.uid()`.
- `ride_recurrence_exceptions` : isolation via FK subquery `ride_recurrences.organization_id`.
- `tariff_grids` : DELETE/UPDATE refusés par absence de policy (versionnement strict DEC-057).
- `holidays_974` / `sms_templates` : référentiels partagés `authenticated true`, INSERT applicatif refusé (seed-only).
