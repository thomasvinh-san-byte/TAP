<objective>
Créer le microservice Python `services/optimizer` : un serveur FastAPI exposant `POST /solve` qui résout un problème PDPTW (Pickup & Delivery Problem with Time Windows) avec OR-Tools, et `GET /health` pour la sonde de disponibilité. SolveRequest (entrée du solveur, Python → reçu en JSON) :
  contract_version: str = "1"          # littéral
  date: str                            # "YYYY-MM-DD"
  rides: list[RideNode]                # min 1, max 200
  vehicles: list[VehicleNode]          # min 1
  depot: tuple[float, float]           # coordonnée de dépôt fictif [lat, lng]
  correction_factor: float             # 1.0..2.0 (DEC-056)
  avg_speed_kmh: float                 # 10..120 (D-12)
  time_limit_seconds: int              # 2..5 (D-05)

RideNode :
  id: str                              # UUID opaque de la course — JAMAIS de nom patient (D-08)
  pickup: tuple[float, float]          # [lat, lng]
  dropoff: tuple[float, float]         # [lat, lng]
  scheduled_at: str                    # ISO 8601 avec offset
  urgency: Literal["programmee", "urgente", "immediate"]
  transport_mode: Literal["taxi_conventionne", "tpmr", "vsl", "ambulance"]

VehicleNode :
  id: str                              # UUID opaque
  type: Literal["taxi", "tpmr", "vsl", "ambulance"]
  places_assises: int                  # 1..20
  places_tpmr: int                     # 0..4

SolveResponse (sortie du solveur, Python → JSON) :
  contract_version: str = "1"
  groupements: list[Groupement]
  rides_non_groupees_ids: list[str]
  rides_exclues_ids: list[str]         # toujours [] côté service — le filtre coords est dans le Route Handler (D-17)
  km_a_vide_estimes: float             # >= 0

Groupement :
  vehicle_id: str
  ride_ids: list[str]                  # >= 2 courses
  order: list[str]                     # ordre de passage (UUIDs)
  motif: str                           # justification courte, <= 120 caractères
  gain_km_a_vide: float                # >= 0
</interfaces>

| Threat ID | Category | Component | Disposition | Mitigation Plan |
