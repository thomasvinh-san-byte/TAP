# Phase 06.24 — CONTEXT

> Incarnation Régulation lot 1 : PageHeader unifié + hiérarchie typographique.
> Premier lot d'incarnation de la direction artistique (DEC-101) sur (app).

## Pourquoi

Friction log Régulation : **(1)** hiérarchie typo écrasée — 206 petits textes (`text-sm`/`text-xs`) vs 15 grands sur (app), niveaux intermédiaires absents → sensation « plate/utilitaire » ; **(2)** en-têtes dupliqués à la main sur 6 écrans alors que le composant `PageHeader` existe et est utilisé par les 16 pages admin → deux grammaires. Ce lot répare les deux. C'est la fondation : sans grammaire typo + en-tête cohérents, le reste se poserait sur du sable.

## État vérifié — bonne nouvelle : tout existe déjà

- **Échelle typo DÉJÀ définie** dans les tokens (xs 12 / sm 14 / base 16 / lg 18 / xl 20 / 2xl 24 / 3xl 30). Le problème n'est PAS l'absence d'échelle : c'est que les écrans n'utilisent que xs/sm. → On APPLIQUE l'échelle.
- **`PageHeader` EXISTE** (`components/page-header/`) avec API stable (`title`, `description?`, `actions?`, `className?`). Rend `<h1 text-2xl font-semibold tracking-tight>` + `<p muted text-sm>`. → On l'ÉTEND au cœur métier.
- Les 6 écrans rendaient un `<h1 className="text-2xl font-semibold tracking-tight">` à la main, IDENTIQUE au h1 de PageHeader → remplacement 1:1, zéro risque visuel.

### D-02 — Exprimer la hiérarchie typographique (réparer le plat)

Standardisation du pattern « kicker » (étiquette de section uppercase) sur **`text-xs font-semibold uppercase tracking-wide`** :

- **Cockpit** : `alerts-panel` aligné `text-sm` → `text-xs`. Les titres de panneaux (`text-base font-semibold` pour « Carte des chauffeurs ») restent — ils représentent un **niveau intermédiaire** légitime (gradation panneau > kicker section > body).
- **Patients** : 12 sections aux classes `text-sm font-semibold uppercase` (sans tracking-wide) → harmonisées vers `text-xs font-semibold uppercase tracking-wide` (cohérence visuelle avec cockpit + pattern shadcn/Linear standard). Touche 6 fichiers : `patient-form-note`, `patient-drawer-sections`, `patient-form-constraints`, `patient-form-sections`, `recurrences-section`, `patients/[id]/page.tsx`.
- **Courses** : les `text-xs` sur métadonnées (compteurs, dates, montants) RESTENT — c'est leur usage légitime (légendes).

**Gradation visible obtenue** :
| Niveau | Pattern | Usage |
|---|---|---|
| Titre page | `text-2xl font-semibold tracking-tight` | PageHeader (1× / page) |
| Titre panneau | `text-base font-semibold` | « Carte des chauffeurs », « Patient absent » (modale) |
| Kicker section | `text-xs font-semibold uppercase tracking-wide` | « Alertes », « Identité administrative », « Coordonnées »… |
| Body lecture | `text-sm` ou `text-base` | descriptions, paragraphes |
| Légende / méta | `text-xs` | compteurs, dates, montants tabular-nums |

C'est ce **CONTRASTE par propriété** (taille + graisse + uppercase + tracking) plutôt que par seule taille qui répare la sensation « plate » (direction DEC-101 §5bis levier 2).
