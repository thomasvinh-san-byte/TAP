# Phase 06.11 — Polish produit — CONTEXT

## Goal

Polir les écrans clés du démo TAP pour atteindre un niveau de finition vendable à un prospect : tableau de bord dirigeant enrichi (3 items), passe UX écran optimisation (5 items), finition générale (2 items). Aucune nouvelle fonctionnalité métier — uniquement du polish sur les surfaces existantes.

## Pourquoi maintenant

Phase 06.10 clôturée 2026-06-03 a stabilisé l'optimiseur (mock activé partout) et scellé le pipeline geocoding. Décision dirigeant : pas de prospect imminent en vue, donc séquence A « optimiser pour la phase tests qui dure » plutôt que séquence B « préparer la production ». Cette phase capitalise le temps disponible avant le 1er prospect sérieux pour rendre le démo dense en signal qualité.
