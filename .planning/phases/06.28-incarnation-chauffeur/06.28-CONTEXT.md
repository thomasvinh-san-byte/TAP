## Décisions fermées

### D-01 — Terracotta sur le moment-clé chauffeur

`ride-actions.client.tsx` ligne 154 : bouton « Démarrer la course » (status `assignee`) → **`variant="accent"`**. Garde `h-14 w-full text-base font-semibold` inchangé.

**NE PAS toucher** :
- « Clôturer la course » reste en `bg-warning` orange — état de FIN distinct, sémantique d'attention/vigilance, pas un moment-clé d'avancement.
- Badges `success` (« Terminée à HH:MM »), neutre (« Course annulée ») inchangés.

Contraste vérifié lot 2 : terracotta `hsl(14 78% 46%)` + blanc = 4.61:1 ✓ AA. OK pour bouton h-14 text-base.

### D-02 — En-tête harmonisé

Page « Ma journée » : `<h1>` manuel + `<header>` flex → migré vers **`<PageHeader>`** avec slot `actions` portant le compteur de courses. Cohérence grammaire avec cockpit + lot 1.

Empty state « Aucune course planifiée » harmonisé :
- Titre `text-lg` → **`text-2xl font-semibold tracking-tight`** (aligné PageHeader pour cohérence visuelle, écran terrain assume la grande taille).
- Texte plus accueillant : « **Pas de course pour l'instant** » + « Vos prochaines courses apparaîtront ici dès qu'elles vous seront assignées. »
- Description passée de `text-sm` à `text-base` (terrain = grande lecture, DEC-101 §6).
- Icône Calendar décorative préservée.

### D-03 — Mode contraste élevé (DEC-014, le vrai manque terrain)

Implémentation socle complète :

1. **Hook `useHighContrast`** (`lib/use-high-contrast.client.ts`) — patterné sur `useTheme` : lit/persiste `localStorage['driver-contrast']`, applique `data-driver-contrast="high"` sur `<html>`, **auto-active si l'OS signale `prefers-contrast: more`** au premier mount (et qu'aucune préférence utilisateur n'est encore stockée).
2. **`<HighContrastToggle>`** (`(driver)/_components/`) — bouton icône Contrast Lucide, posé dans le header driver entre `ConnectionStatusBadge` et `UserMenu`. A11y : `aria-pressed`, label parlant, cible 40px alignée sur les autres icônes du header.
3. **CSS overrides dans `globals.css`** — sous `[data-driver-contrast='high']` et `@media (prefers-contrast: more)` :
   - `--border` clair `214 32% 91%` → **`214 50% 45%`** (gris bleuté tranché)
   - `--input` aligné sur border
   - `--muted-foreground` clair `215 16% 47%` → **`215 30% 25%`** (texte secondaire bien plus foncé)
   - En sombre : `--border` → `214 50% 75%`, `--muted-foreground` → `215 30% 85%`
4. **0 hex en dur** — uniquement des overrides de CSS vars HSL.
5. **`--foreground` non touché** — déjà très foncé en clair (`222 47% 11%`) et très clair en sombre (`210 40% 96%`), rien à gagner.

Persistance + auto-detection couvrent l'essentiel ; les chauffeurs avec OS contrast déjà actif n'ont rien à faire.
