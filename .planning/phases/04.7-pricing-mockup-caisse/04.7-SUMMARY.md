## Trouvailles et apprentissages

### Apprentissage 1 — Vélocité GSD à -85% confirmée

Phase 04.7 a livré 3 plans + Wave A + verify en ~45 min exécution + ~25 min hotfix-bis + ~30 min verify = ~1h40 cumulé pour 4-5.5h estimé. Vélocité observée -85% maintenue depuis Phase 04.5 (-73% sur exécution seule).

### Apprentissage 2 — Audit codebase pré-plans paie

L'audit codebase de PR #88 Discuss a sourcé immédiatement le Tronc 4 caduc (anonymisation seed déjà faite Phase 3). Sans cet audit, ~30 min auraient été perdues à dupliquer une migration existante.

### Apprentissage 3 — Méthodologie UAT informel validée par exercice réel

L'UAT informel Phase 04.7 (premier cas concret post-inscription VISION.md PR #97) a effectivement révélé 3 frictions invisibles à la spec UI-SPEC :

- F1 modal width : combinaison POI long × DialogContent max-w fragile (bug de combinaison, pas de spec individuelle)
- F2 filtre date : manque UX révélé par usage réel (oubli symétrie page caisse vs page courses)
- F3 pagination : V1 hardcoded `.limit(100)` sans feedback, observable seulement > 30 rides

Coût UAT 15-30 min + hotfix 25 min = ~40-55 min total, rentable face au coût d'une friction démo live design partner. La méthodologie VISION.md PR #97 tient son rôle dès son premier usage.

### Apprentissage 4 — Politique abonnement PR maintenue

Aucune subscribe automatique sur les 7 PR Phase 04.7 (#88, #90, #91, #92, #93, #94, #95, #96, #97, #98). Le dirigeant reçoit les notifications GitHub par mail. Silence radio entre checkpoints respecté. Verrou VISION.md PR #91 « Politique d'abonnement PR » validé.
