## Surface A — PricingBreakdown (composant inline)

**But** : afficher le détail du tarif calculé par `computeCgssShortTrip` (stub T1.1) avec badge « DEMO » visible pour rappeler que ce n'est pas le calcul CGSS final. Inline dans `end-ride-modal.client.tsx` (vue chauffeur) et `ride-drawer.client.tsx` (vue régulateur post-clôture).

### Spec composant

**Fichier** : `apps/web/src/app/(app)/courses/_components/pricing-breakdown.client.tsx` (NEW)

**Props :**

```ts
interface PricingBreakdownProps {
  /** Résultat de computeCgssShortTrip (T1.1) */
  pricing: PricingResult;
  /** Si true, affiche le bouton « Modifier » qui appelle onOverride */
  editable?: boolean;
  /** Callback override — ouvre Surface B (OverrideTarifModal) */
  onOverride?: () => void;
}

interface PricingResult {
  forfait_eur: number;        // ex : 4.20
  distance_km: number | null; // null si fallback random (DEC-042)
  prix_km_eur: number | null; // ex : 2.10, null si fallback
  km_total_eur: number | null;// distance × prix, null si fallback
  majo_nuit_pct: number;      // 0 ou 20
  majo_nuit_eur: number;      // calculé
  supp_tpmr_eur: number;      // 0 ou 5
  total_eur: number;          // total final
  source: 'haversine' | 'fallback_random'; // DEC-042
}
```

**États visuels :**

| État | Comportement |
|---|---|
| `source = haversine` | Affichage normal, badge « DEMO » discret |
| `source = fallback_random` | Bandeau warning R3 (`bg-warning/10 + border-warning/30`) au-dessus du détail : « Distance non calculable. Tarif estimé. » |
| `editable = true` | Bouton « Modifier » à côté du total, ouvre Surface B |
| `editable = false` | Read-only, pas de bouton |

## Risques UI

### A11y

- **Sheet B** : risque focus trap mal géré si on imbrique avec un Dialog parent. Mitigation : tester `Esc` ferme Surface B sans fermer le drawer parent.
- **Table tri C** : `aria-sort` doit être mis à jour à chaque tri (pas seulement DOM). React state sync.
- **Toast Sonner** : `role="status"` ou `role="alert"` selon criticité. Export = status, erreur = alert.

### Mobile

- **Surface A inline** : déjà bien sur mobile (dans drawer/modal qui sont responsives).
- **Surface B Sheet** : sur mobile, Sheet shadcn passe en bottom sheet automatiquement (responsive built-in).
- **Surface C table** : risque scroll horizontal sur mobile. Mitigation V1.5 : la caisse est primarily desktop (régulateur en bureau). Une vue mobile dédiée est différée Phase 04.9.

### Perf

- **Surface C** : si ≥ 100 rides/jour, le tri client devient lent. Mitigation : pagination serveur si > 50 rides, et tri serveur via URL params.
- **Export CSV** : streaming server-side pour ne pas bloquer Node event loop sur gros volumes (1 mois = ~3000 rides).

### UX dérive

- **Badge DEMO Surface A** : doit rester visible jamais masqué accidentellement par un wrapper parent. Toujours `flex-shrink-0`.
- **Override Surface B** : motif 10 chars min trop court (le dirigeant peut écrire « ok ok ok ok »). À élever à 30 chars min en UAT si abus observé.
