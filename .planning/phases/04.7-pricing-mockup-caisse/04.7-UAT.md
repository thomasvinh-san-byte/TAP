### Scénario 5 — Vérification frictions préliminaires (UAT dirigeant)

**Friction 1 — Modal « Nouvelle course » largeur cassée**

Verification code :
- `ride-express-modal.client.tsx:194` avant hotfix : `className="max-w-[600px]"` sans `w-[calc(100vw-32px)]` ni `overflow-x-hidden`
- POI long en seed : « CHU Sud Saint-Pierre — Avenue du Président Mitterrand, Terre-Sainte, 97410 Saint-Pierre » (~92 chars)
- Cause root : DialogContent max-w trop fragile, picker pill manquait `flex-1` (renforce truncate sur enfants), pas de tooltip valeur complète

**Résultat : CONFIRMÉ** → hotfix 04.7-bis livré (PR #98)

**Friction 2 — Filtre date page /courses**

Verification code :
- `rides-list.client.tsx:64-65` avant hotfix : seulement `statusFilter` + `modeFilter`
- `listRidesEnriched` ne supportait pas param `date`
- Cause root : oubli dans UI-SPEC Phase 04.5 (T2.1 caisse a un filtre date, mais page /courses générale non — par symétrie aurait dû avoir)

**Résultat : CONFIRMÉ** → hotfix 04.7-bis livré (PR #98)

**Friction 3 — Pagination page /courses**

Verification code :
- `_lib/queries-enriched.ts:51` avant hotfix : `.limit(100)` hardcoded
- Pas de mécanique offset/cursor, pas de bouton « Voir plus »
- Cause root : V1 minimale Phase 03, scope étendu mais perf > 30 rides observable seulement en démo réelle

**Résultat : CONFIRMÉ** → hotfix 04.7-bis livré (PR #98)

## Décision hotfix-bis : **Cas A** confirmé

Aucune friction nouvelle au-delà des 3 préliminaires. Les 3 sont fixées dans le hotfix 04.7-bis (PR #98) :

| Fix | Cause root | Solution |
|---|---|---|
| F1 modal | `max-w-[600px]` sans contraintes viewport | `w-[calc(100vw-32px)] max-w-[640px] max-h-[90vh] overflow-y-auto overflow-x-hidden` + pill `flex-1` + `title={value}` tooltip |
| F2 filtre date | Pas de param `date` sur query ni input UI | Input `type="date"` défaut aujourd'hui + bouton Effacer + extension `listRidesEnriched.date` + Zod validation |
| F3 pagination | `.limit(100)` hardcoded, pas de feedback UI | `PAGE_SIZE=50` + `.range(offset, offset+limit-1)` + state cumulatif + bouton « Voir plus » + compteur « X affichées » |

**Pattern méta validé** : UAT informel post-execute Phase 04.7 a effectivement révélé 3 frictions invisibles à la spec UI-SPEC. La méthodologie VISION.md PR #97 tient son rôle.

**Coût hotfix-bis : ~25 min réel** (vs 15 min estimé, sur-estimation légère mais sous time-cap V5 1h).
