Notes de design pour Claude Code (à reprendre dans le prompt 03-E)

  • Bandeau couleur 4px en haut de chaque carte, encode le statut visuellement : assignee gris neutre, en_cours warning orange (action requise), terminee success vert.
  • Heure scheduled_at en grand (text-2xl), tabular-nums obligatoire, format HHhMM français.
  • Adresses dans un sous-bloc bg-muted/50 avec icônes Lucide MapPin (pickup) → ArrowDown → Navigation (dropoff). Code postal + ville en muted sur la ligne suivante.
  • Bouton primaire h-14 (56px) pleine largeur, label contextuel selon statut. Couleur primaire pour Démarrer, warning orange pour Clôturer (action urgente), bouton désactivé style success pour Terminée.
  • Carte terminée grisée à 70% d'opacité sur le trajet, garde le bandeau vert, montant encaissé visible dans la meta du patient (« 28,50 € encaissés cash »).
  • Modal clôture en bottom-sheet sur mobile (items-end), centré sur desktop (items-center). Grabber visuel 4px en haut sur mobile.
  • Input tarif en grand (text-3xl), tabular-nums, focus visible par border-primary + background blanc. La virgule française est conservée (28,50 et non 28.50).
  • Payment method grid 2×2 : cash / CB / chèque / CGSS différé. Sélection avec border-primary + background info-bg. Icônes Lucide ligne fine.
  • Switch encaissé ON par défaut (success vert) car cas le plus fréquent (cash, CB). Si OFF, payment_status = a_encaisser.
  • Empty state illustration Lucide simple (Calendar) + texte FR + sous-titre apaisé (« Profite de ta journée. »). Pas d'illustration colorée enfantine.
  • Background driver teinté hsl(45 100% 99%) pour ancrer le contexte chauffeur (cf. 03-C).
  • Mode nuit à traiter à parité (non illustré ici).
